# MuldjordKit (FreePats version)

Recorded by **Lars Muldjord** in 2009-2010 (the original kit is made for
[DrumGizmo](https://www.drumgizmo.org)); this stereo version was assembled by
Roberto (roberto@zenvoid.org) for the **FreePats** project. A rock / metal kit:
2 kicks, 3 hanging toms, 1 floor tom, 1 snare, 1 hi-hat, 2 crashes, 2 rides,
1 china, with velocity layers.
