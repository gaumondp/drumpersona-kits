# GeneralUser GS

A General MIDI SoundFont by **S. Christian Collins**, version 2.0.3: a whole
General MIDI bank (pianos, guitars, strings...) with 13 drum kits, already on the
General MIDI keys: Standard 1, 2 and 3, Room, Power, Electronic, 808/909, Dance,
Jazz, Brush, Orchestral, SFX and CM-64/32L. DrumPersona imports only the drum
kits (one kit each; the file has them in bank 128 and again in 120).

- Source: [schristiancollins.com/generaluser.php](https://www.schristiancollins.com/generaluser.php),
  file from the author's repository
  [mrbumpy409/GeneralUser-GS](https://github.com/mrbumpy409/GeneralUser-GS)
